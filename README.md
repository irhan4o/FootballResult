# FootballResult

Уеб приложение за управление на футболни резултати и мачове.

## Технологии

- ASP.NET Core 8
- Entity Framework Core
- SQLite / SQL Server

## Стартиране

```bash
dotnet restore
dotnet run --project FootballResult/FootballResult.csproj
```

След стартиране отворете адреса, показан в конзолата.
